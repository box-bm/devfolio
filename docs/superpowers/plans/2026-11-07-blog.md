# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a personal, bilingual `/blog` section (empty state, no post yet) that shares its plumbing with guides but reads like essays, not how-tos.

**Architecture:** A new `blog` content collection and `/blog` routes mirror the guides wiring. Guide-only logic moves into a shared `posts` helper (pure functions, unit-tested) plus a `getPosts` collection reader; `guides.ts` becomes a thin wrapper so guide URLs and output do not change. The guide page's "taped portrait + note" ending is extracted into `SignOff.astro` and reused by the blog.

**Tech Stack:** Astro 5 (content collections, `astro:assets`), TypeScript, Vitest, Prettier (`prettier-plugin-astro`), `gh` for the PR.

**Spec:** `docs/superpowers/specs/2026-11-07-blog-design.md`

## Global Constraints

- English at `/`, Spanish at `/es/`; every string and every post ships in both languages.
- All translated strings go through `UiKey` enum values, never raw strings. Add a key to `src/i18n/ui.ts`, `en.ts` and `es.ts` together.
- Use the EN/ES copy table in the spec verbatim.
- Path aliases only: `@components`, `@layouts`, `@styles`, `@images`, `@i18n`, `@utils`, `@constants`.
- Existing `/guides/...` URLs and the guide page's visual output must not change. Drafts are excluded by the helper exactly as `getGuides` does today.
- Blog frontmatter: `title` (required), `description`, `topic`, `date` (required), `updatedDate` (optional), `draft` (default `false`). No `tags`.
- Follow `DESIGN.md` (sketchbook: graphite, blue pencil, Schibsted Grotesk; Kalam only in `.pencil-note`). Use existing tokens (`--pencil`, `--surface`, `--text-secondary`, …); no new colors.
- No home page section, no header link, no RSS/comments/tag pages. Only entry point is the footer "Explore" link.
- Posts are public and indexed by default (spec default).
- Format with `npx prettier --write` on changed files before each commit. Commit trailer: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Zero blog posts: `/blog` and `/es/blog` render the empty state, `[slug]` generates no paths, and `npm run build` passes. (Task 5)
2. Exactly one post: no newer/older nav renders, and nothing wraps around to itself. (Task 5)
3. A post with only an `.en.md` and no `.es.md` (or the reverse) fails the parity test. (Task 2)
4. A `draft: true` post is absent from the index, the route and the sitemap. (Task 5)
5. A post with no `description` or `topic` renders no empty elements, and a title with `&`, `?` or accents produces a valid `mailto:` subject. (Tasks 1, 5)

Slugs must not contain dots (`id.split(".")[0]` convention); Task 1 pins this.

### Task 1: Shared post helpers

**Files:**

- Create: `src/utils/posts.ts`, `src/utils/getPosts.ts`, `tests/posts.test.ts`
- Modify: `src/utils/guides.ts`

**Interfaces:**

- Produces (`posts.ts`):
  - `type PostCollection = "guides" | "blog"`
  - `type PostLike = { id: string; data: { date: Date } }`
  - `postSlug(post: { id: string }): string`
  - `postHref(collection: PostCollection, post: { id: string }, lang: Lang): string` → `/${lang}/${collection}/${slug}`
  - `postDateFormat(lang: Lang): Intl.DateTimeFormat` (same options and `America/Guatemala` zone as today's `guideDateFormat`)
  - `readingMinutes(body?: string): number` (same 220 wpm logic as today)
  - `forLang<T extends PostLike>(posts: T[], lang: Lang): T[]` — keeps ids ending `.${lang}.md`, newest first
- Produces (`getPosts.ts`): `getPosts(collection: PostCollection, lang: Lang)` returning published entries (draft excluded) via `forLang`.
- `guides.ts` keeps exporting `getGuides`, `guideSlug`, `guideHref`, `guideDateFormat`, `readingMinutes` with unchanged signatures.
